# Future Scope

## Product

- Live payment flow with UPI/payment gateway integration
- Booking cancellation and refunds
- Admin charts for weekly/monthly occupancy and revenue
- Driver saved places and favorite parking lots
- Real photo upload with Firebase Storage
- Push notifications for booking expiry

## Routing And Maps

- OpenStreetMap tile rendering
- OSRM/OpenRouteService route provider
- Google Maps provider for teams with billing enabled
- ETA and traffic-aware route scoring

## QR And Gate Verification

- Server-side signed QR payloads
- Gate scanner API
- Entry/exit audit logs
- Grace period and overstay billing

## Backend

- Firestore security rules
- Cloud Functions for atomic slot booking
- Aggregated counters for admin dashboard performance
- Emulator-based local Firebase testing
