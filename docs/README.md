# Park Here

Park Here is a local-first MVP for a parking occupancy system with two Flutter apps:

- **Park Here** for drivers
- **Park Here: Location Administrator** for parking owners

The product starts from a simple city problem: people waste time circling for parking while owners manage availability manually. The MVP gives both sides a shared booking model, map-first discovery, route selection, QR-ready booking tickets, and a Firebase-ready backend shape.
